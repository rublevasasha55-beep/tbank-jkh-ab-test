# A/B-тест формы оплаты ЖКХ

Это учебный аналитический проект по кейсу из отбора на стажировку Т-Банка. Я разобрала результаты A/B-теста новой формы оплаты ЖКХ: проверила качество данных, рассчитала конверсию и оценила, насколько убедительно различие между группами.

**Задача:** понять, помогает ли упрощённое заполнение реквизитов чаще доводить оплату до успешного завершения.

## Что получилось

- **Группа A:** 49,77% успешных оплат.
- **Группа B:** 64,40%.
- **Разница:** +14,63 процентного пункта.
- **95%-й доверительный интервал:** от +10,96 до +18,25 п. п.
- **Перестановочный тест:** p ≈ 0,00020.

Группа B показала более высокую конверсию. Если именно ей показывали новую форму, результаты поддерживают её поэтапный запуск после проверки стабильности платежей.

В условии не указано, какой группе показывали новый интерфейс, поэтому я учитываю это ограничение в выводах.

## Что я сделала

1. Изучила данные пользователей и платежей, проверила пропуски, дубликаты и некорректные записи.
2. Подготовила данные для анализа: осталось 2 659 попыток оплаты от 1 501 клиента.
3. Рассчитала конверсию по попыткам и по пользователям, сравнила этапы воронки.
4. Проверила статистическую значимость различий с учётом повторных попыток клиентов.
5. Проверила устойчивость результата и подготовила рекомендацию.

## Материалы проекта

- `analysis.ipynb` — подробный ход исследования и расчёты.
- `report/tbank_jkh_ab_report.pdf` — итоговый отчёт на двух страницах.
- `figures/` — графики воронки и конверсии.
- `requirements.txt` — необходимые библиотеки Python.

## Как запустить

Создать виртуальное окружение, установить зависимости из `requirements.txt`, поместить Excel-файл в `data/ab_test_jkh.xlsx` и открыть `analysis.ipynb` в VS Code.

Для запуска ноутбука необходимо выбрать ядро Python из `.venv`.

Исходный Excel не опубликован. Результаты вычислений и графики сохранены в ноутбуке.
